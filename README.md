# LUNA 1300 PRO · Laboratuvar Föyleri

Safety 4.0 derslerinin ilk dört haftasında yaptığım çalışmalar. Hepsini tek bir gerçek makine üzerinden yürüttüm: Bursa'daki Baromak firmasının ürettiği **LUNA 1300 PRO otomatik fırça zımpara makinesi** ([ilan](https://twm.com.tr/tr/ilan/luna-1300-pro-firca-zimpara-makinesi), [üretici sayfası](https://baromak.com.tr/urun-detay.html?id=luna-1300-pro)).

Makinede 6 osilasyonlu fırça istasyonu, çekmeceli bakım istasyonları ve üreticinin 7/24 bağlanabildiği bir uzaktan bağlantı var. Föylerin çoğu bu üçünün etrafında dönüyor.
